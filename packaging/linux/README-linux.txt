TorBox STRM for Linux
=====================

Run ./torbox_strm_player from this folder.

The app uses the system WebKitGTK and libmpv. On Debian / Ubuntu 24.04:

    sudo apt install libwebkit2gtk-4.1-0 libmpv2 libgtk-3-0

Fedora: sudo dnf install webkit2gtk4.1 mpv-libs gtk3
Arch:   sudo pacman -S webkit2gtk-4.1 mpv gtk3
